# Пример 1: Логирование выполнения функции
# Если нужно автоматически записывать, когда и какие функции вызываются, можно использовать декоратор для логирования.

# Пример 2: Кеширование результатов в вычислениях
# Когда у нас есть сложные вычисления, декораторы помогают избежать повторных вычислений и ускорить работу программы.

# Пример 3: Ограничение доступа по ролям
# В админ-панелях часто бывает логика доступа. Декоратор позволяет легко ограничивать функционал для обычных пользователей.
